Прежнее описание объединённой Camera 0.6–0.8 сохранено в [CAMERA_LEGACY.md](CAMERA_LEGACY.md) для существующих проектов.

✅ **2026-11-12 — подготовлена доработка OFX SilentFilm Camera Optics.** Это текущий этап после Cadence 0.17. Сборки, тесты и Resolve агент не запускал; PASS новой оптики пока не подтверждён.

Используй **SilentFilm Camera Optics** из группы ALEXZ/SilentFilm. Рабочая цепочка: **Cadence → Camera Optics → Negative → Print → Projector**. OFX обрабатывает текущий кадр: виньетку, краевой расфокус, общую мягкость, гуляние фокуса и монохромный отклик. Вход — SDR sRGB/примарии Rec.709. Экспозиция и неравномерность ручки уже записаны в ролик Cadence; повторная старая Camera для этого не нужна.

## Параметры

| Контрол | Действие и удобные значения для проверки |
|---|---|
| `vignette_strength` | Затемнение по радиальной маске. 0 выключает, 0.12 — исходное значение; для проверки 0.5. Не управляет расфокусом |
| `edge_start` | Радиус начала виньетки и краевого размытия в единицах половины ширины; исходно 0.6 |
| `edge_end` | Радиус полной силы; исходно 1.0, должен быть больше `edge_start` |
| `edge_softness` | Краевой расфокус, локальная sigma растёт по маске. Максимум `ширина × 0.025 × сила`. При 1920 px и 0.15 — 7.2 px; центр до `edge_start` сохраняется, если другие размытия выключены |
| `softness` | Постоянный расфокус всего изображения. Sigma = `max(0.1, ширина / 1920 × сила × 4)` при ненулевой силе. При 1920 px: 0.1 → 0.4 px, 0.5 → 2 px; 0 полностью выключает |
| `focus_drift_strength` | Переменный дополнительный расфокус всего кадра поверх `softness`. Максимальная sigma = `ширина / 1920 × сила × 8`. Исходно 0.03; для заметной проверки 0.3–0.5 на детализированном клипе |
| `seed` | Выбор воспроизводимого рисунка фокуса. Перемотка и другой порядок запросов кадров не меняют результат при той же длине клипа/seed |

Сила фокуса — не прямой радиус: сигнал задаёт промежуточное значение между соседними Gaussian-уровнями. При малом разрешении малые значения могут быть почти незаметны. Значения sigma указаны в пикселях обрабатываемого кадра, а не полного исходника при proxy.

Маска круговая в координатах растра, как в Comfy; отдельной компенсации неквадратного pixel aspect в этой модели нет. Alpha сохраняется, RGB unpremultiply/premultiply согласован с форматом хоста. Выход монохромный даже при нулевых оптических параметрах: выключение размытия и виньетки не отключает ЧБ-отклик.

## Математика и вычисления

Порядок: переменный краевой Gaussian → виньетка → общий Gaussian → переменный Gaussian фокуса → монохром. Уменьшение для широкого Gaussian соответствует PyTorch `area`/adaptive average pooling: целые границы корзин и равные веса, включая перекрытия при неделимых размерах. Округление рабочего размера — nearest-even, как Python `round`. Затем separable Gaussian с reflect либо replicate на маленьких изображениях и bilinear увеличение с `align_corners=False`. Прежние взвешенные геометрические площади и `std::round` давали другое изображение; исправлены CPU и CUDA.

Фокус повторяет структуру Comfy: AR(1) со smoothing 0.48/drive 0.52, начало с нуля, вычитание среднего и нормализация population std по всему клипу, затем tanh. Получается воспроизводимый кэш на экземпляр OFX, защищённый mutex; указателей изображений хоста в нём нет. На одном кадре фокус выключен. При изменении длины или seed сигнал перестраивается, поэтому подрезка может изменить его рисунок. Используется нативный Gaussian RNG: одинаковый seed **не обещает** одинаковой последовательности с Torch. Старая Camera сохраняет прежний локальный сигнал фокуса для совместимости.

На CPU линейные операции перенесены на одну ЧБ-плоскость: взвешивание RGB коммутирует с этой оптикой, различается только порядок float-округлений. В этом пути нет повторного decode/encode экспозиции. На CUDA RGB обрабатывается вместе, кадр остаётся в VRAM, используется переданный stream; при gain=1 лишнее decode/encode тоже исключено. При отсутствии размытия CUDA обрабатывает виньетку/ЧБ без промежуточных буферов. Численное ускорение не измерено.

Экспозиция Cadence и оптика здесь разделены по ранее принятому workflow. Это не обещает полного end-to-end равенства порядку операций единой Comfy Camera, где экспозиционный gain применяется после оптики.

## Сборка и проверки пользователем

```bash
cd /home/alex/Projects/ALEXZ_SilentFilm_OFX
cmake --build build-cuda --parallel 2 &&
ctest --test-dir build-cuda --output-on-failure
```

Добавлены `silentfilm_camera_optics` и `silentfilm_camera_optics_cuda_parity`: аналитическая виньетка/ЧБ, alpha, нормализация фокуса, воспроизводимость, сильный расфокус, размеры с половинным округлением, маленькие кадры. CPU-путь отдельно проверяет отрицательный stride, смещённые bounds, ROI/неизменность padding и отмену. Прежний Camera CPU/CUDA parity также нужен: общая Gaussian-функция используется старой Camera.

Дополнительная независимая сверка с настоящими функциями Comfy запускается из существующего Python-окружения с NumPy/Torch (того же, где сравнивался flow). Новых зависимостей у OFX нет; референс только читается, Comfy не запускается:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 tests/compare_comfy_optics.py --backend cpu
PYTHONDONTWRITEBYTECODE=1 python3 tests/compare_comfy_optics.py --backend cuda
```

CPU/CUDA native test выбирается по backend. Проверяются 9 входов и заданные значения сигнала фокуса; это сверка пространственной математики, не совпадения RNG. Допуски: max_error ≤ 8e-5, mean_error ≤ 8e-6. Подтверждённого вывода этих сравнений пока нет.

После успешных тестов закрой Resolve и сам обнови bundle:

```bash
sudo cp -a build-cuda/ofx/ALEXZSilentFilm.ofx.bundle /usr/OFX/Plugins/
```

Ручная проверка на таблице резкости/детализированном кадре: сначала `vignette_strength`, `edge_softness`, `softness`, `focus_drift_strength` = 0. По одному включай виньетку 0.5, краевой расфокус 0.3, общий расфокус 0.5. Затем на клипе выключи остальные эффекты и поставь фокус 0.5: сравни несколько удалённых друг от друга кадров и повторную перемотку на тот же кадр. После проверки верни деликатные значения и добавляй Negative/Print. Для новой версии прежний Resolve render cache нужно обновить, если он показывает старый результат.
