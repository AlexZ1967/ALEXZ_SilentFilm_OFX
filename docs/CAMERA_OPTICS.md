# SilentFilm Camera: статическая виньетка

## Состояние

В версии 0.4 добавлен отдельный эффект OpenFX **SilentFilm Camera**, ID `com.alexz.silentfilm.camera`. Сейчас он реализует только неподвижную круговую виньетку съёмочного объектива. Каденс, покачивание, переменный фокус и размытие не входят в этот эффект.

Код обрабатывает RGB в исходном кодировании и сохраняет alpha. Это умножение яркости маской, а не цветовое или тональное преобразование. Один и тот же пиксельный код используется на CPU и CUDA. Центр и размер маски берутся из полных bounds исходного image, поэтому обрезанный render window не перемещает виньетку. Используются координаты пикселей: поправка на pixel aspect ratio пока не предусмотрена.

## Параметры

| Параметр | Действие и старт |
|---|---|
| `Vignette Strength` | 0 — выключено; 0,10–0,15 — лёгкое затемнение; 0,6 — выраженное. В областях полной маски RGB умножается на `1 − strength`; alpha не меняется. |
| `Edge Start` | Радиус начала затемнения в единицах половины ширины кадра. 1 — половина ширины. Старт 0,6; уменьшение расширяет маску к центру. |
| `Edge End` | Радиус достижения полной силы маски. Старт 1,0. Должен быть больше Edge Start. При значении за углами кадра полная сила внутри кадра не достигается. |

Маска плавно переходит от 0 к 1 между Edge Start и Edge End через smoothstep. За пределами Edge End маска равна 1. Для нейтрального изображения поставьте `Vignette Strength = 0`.

## Проверка пользователем

Сборка и проверка в Resolve для версии 0.4 не выполнялись агентом.

1. Пересоберите bundle обычной командой проекта и выполните CTest самостоятельно.
2. После закрытия Resolve замените bundle и проверьте, что в Effects появились **SilentFilm Camera**, **SilentFilm Negative** и **SilentFilm Print**; Host Probe должен остаться доступен.
3. Поставьте Camera перед Negative. Сначала проверьте `Vignette Strength = 0`, затем 0,12 и 0,6 на равномерном сером поле.
4. Изменяйте Edge Start/End. Центр кадра должен оставаться без затемнения до Edge Start; внешний край должен плавно темнеть. Убедитесь, что Edge End больше Edge Start.
5. Повторите на другом разрешении и render window, затем проверьте RGBA с полупрозрачностью. Альфа должна остаться прежней.
6. При доступном CUDA backend проверьте тот же кадр на CPU и CUDA и посмотрите трассу `ResolveDebug.txt`.

Результаты версии 0.4 пока не подтверждены; пользователь планирует проверить накопившиеся изменения пакетом.
