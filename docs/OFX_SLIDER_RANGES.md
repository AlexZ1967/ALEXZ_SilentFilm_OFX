OpenFX разделяет допустимые значения и диапазон UI-ползунка. Например, Dust Size управляется ползунком0.01–0.20, но ввод0.3 или1 вручную остаётся допустимым, как раньше. Значение пресета за пределами рабочей шкалы не обрезается нашим кодом. Подсказки сообщают о ручном вводе больших значений. Реальный вид/шаг контрола зависит от реализации хоста и требует проверки Resolve.

## Проверка пользователя

```bash
cd /home/alex/Projects/ALEXZ_SilentFilm_OFX
cmake --build build-cuda --parallel 2 &&
ctest --test-dir build-cuda --output-on-failure
```

После успешной сборки/тестов закрой Resolve и обнови bundle:

```bash
sudo cp -a build-cuda/ofx/ALEXZSilentFilm.ofx.bundle /usr/OFX/Plugins/
```

Проверь:

1. Dust/Scratches Size: ползунок0.01–0.20, видны тысячные доли. Ввод0.3 или1 вручную принимается; реальный Size/кадр меняются, Save/Apply пресета с большим значением не обрезает его до0.2.
2. Переключи Pattern между Dust/Stains/Development: подпись и шкала меняются, само число Size не переписывается.
3. Camera Optics Focus Drift/Softness, зерно Negative/Print и лампа Projector настраиваются мелко; введи вручную значение выше рабочего предела, но ниже прежнего Min/Max.
4. Открой старый проект/пресет и проверь сохранность значений, анимации и вида. Убедись, что Shadow Compression по-прежнему доступен ползунком до5.

Новые автотесты для перестановки этих обратимых UI-метаданных не добавлены. Существующий CTest и ручной host-check выполняет пользователь; агент PASS не заявляет.
