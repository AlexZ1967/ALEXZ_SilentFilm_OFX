# План Linux-first реализации SilentFilm для Resolve

## Границы

- Новый независимый C++17/OpenFX-проект. Существующий ComfyUI SilentFilm и его workflows не меняются.
- Первый хост — установленный Resolve Studio 20.2 под Linux x86_64. Windows/macOS добавляются после подтверждения базового контракта.
- Python-версия служит эталоном математики. В будущем общий native core можно подключить к Python отдельной задачей.
- Не обещаем автоматическое изменение монтажной длительности клипа обычным OFX-фильтром. Каденс при постоянной длительности и retime — разные режимы, требующие проверки возможностей Resolve.

## 2. Добавить Linux CUDA — исходники подготовлены, проверки ожидаются

✅ **2026-11-06 — подтверждённая часть этапа:** пользователь подтвердил Release-сборку и CTest 2/2 PASS, включая выполненный CUDA parity; в Resolve подтверждён CUDA backend и temporal render-запросы. Отмена, экспорт и оба контекста Color/Fusion отдельно не подтверждены.

Сначала изучить negotiated GPU properties и host stream на установленном Resolve. Добавить CUDA backend к тому же gain/temporal probe, сохранить CPU как эталон. CPU-указатели и CUDA-указатели не смешивать; включать поддержку GPU в descriptor только после реализации соответствующего render path. Учесть lifetime входных кадров и асинхронного stream.

Сравнить CPU/CUDA на коротком клипе. Выяснить, какие temporal-запросы и буферы доступны на GPU в Color и Fusion. Только после этой проверки выбирать реализацию temporal optical flow.

Подготовлен CUDA kernel с общей CPU/CUDA пиксельной функцией, signed stride и раздельными bounds кадров. OpenFX adapter читает `CudaEnabled` и `CudaStream`, не разыменовывает GPU-указатели на CPU, не создаёт собственный device/context и не использует глобальную синхронизацию. Сборка включается через `SILENTFILM_ENABLE_CUDA=ON`, CUDA runtime статический. Добавлен тест сравнения CPU/CUDA на малых буферах с padding, изменёнными origins, отрицательным stride, HDR/alpha и двумя режимами stream. Код не собирался и не запускался агентом. Команды и сценарий — в `CUDA_VALIDATION.md`.

Пользователь подтвердил успешную Release-сборку GCC 13.3 / NVIDIA CUDA 13.0.88 (архитектура 86), создание bundle и CTest 2/2 PASS; GPU parity test выполнен, не пропущен. ## 5. Перенести Camera/Cadence

- Windows x64: нативная сборка, bundle, CUDA/OpenCL при поддержке хоста.
