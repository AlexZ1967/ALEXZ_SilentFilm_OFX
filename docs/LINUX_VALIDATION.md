# Ручная проверка первого OFX-прототипа

Все действия выполняет пользователь. Не ставьте большой рендер до подтверждения короткого сценария. SDK и установленные файлы Resolve не редактируются.

## 1. Сборка и тест ядра

```bash
cd /home/alex/Projects/ALEXZ_SilentFilm_OFX
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DOFX_SDK_ROOT=/opt/resolve/Developer/OpenFX
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

При ошибке пришлите вывод начиная с первой ошибки компилятора или CMake. CTest проверяет только математику ядра: он не доказывает работоспособность ABI, host images и временного доступа в Resolve.

## 2. Проверка загрузки

После установки bundle по README откройте отдельный тестовый проект Resolve с коротким прогрессивным клипом и движущимся объектом. Начните с 1920×1080 и 25 fps; это не ограничение эффекта, а удобная первая проверка.

Найдите **SilentFilm Host Probe** в OpenFX. Если эффекта нет или он отключён, сохраните сообщение из Video Plugins и соответствующий фрагмент `ResolveDebug.txt`. Подключённый в Fusion OpenFX также следует проверить отдельно.

## 3. Пиксельная обработка

1. Поставьте `Diagnostic Gain=0`, `Temporal Mix=0`: изображение должно совпасть с bypass.
2. `Diagnostic Gain=1`: RGB удваивается в том кодировании, которое получил плагин. Это не утверждение о физической экспозиции Log-видео. Альфа не умножается.
3. Верните gain в 0. Проверьте анимацию параметра и несколько экземпляров эффекта.
4. Если доступен RGBA-клип, проверьте прозрачность на checkerboard. Все входные изображения должны иметь согласованную premultiplication, задаваемую хостом.

## 4. Временной доступ

1. Установите `Temporal Mix=1`, `Neighbor Offset=1` на движущемся фрагменте: появится смешивание трёх кадров.
2. Измените offset на 4: расстояние между изображениями движущегося объекта должно увеличиться.
3. Повторно откройте тот же кадр после перемотки назад/вперёд: результат должен воспроизводиться.
4. Проверьте первый и последний кадры, обрезанный клип и затем Fusion. Фиксируйте различия: допустимый диапазон источника задаёт Resolve.
5. При отсутствии temporal support ожидается понятная ошибка, а не незаметная имитация работы. Для продолжения одиночной CPU-проверки верните mix в 0.

Для трассировки запустите Resolve из терминала после закрытия уже работающего экземпляра:

```bash
ALEXZ_SILENTFILM_OFX_TRACE=1 /opt/resolve/bin/resolve
```

Это пример добавления переменной к запуску; если ваш установленный Resolve требует собственного launcher, сохраните его обычные настройки и добавьте переменную перед ним. При нейтральном эффекте host может использовать identity без render, поэтому для трассировки включите temporal mix или ненулевой gain.

## 5. Экспорт и отмена

Экспортируйте 8–16 кадров средствами Resolve. Сравните результат с просмотром. Прервите тестовый экспорт и проверьте, что Resolve остаётся отзывчивым. Затем повторите короткий экспорт. Производительность этого CPU-прототипа не является оценкой будущего GPU SilentFilm.

## Отчёт

Пришлите результаты CMake/CTest и отдельно результат проверки Resolve: версия, Color/Fusion, gain, temporal mix, границы, короткий экспорт и замеченные ошибки. Пока эти результаты не получены, этап взаимодействия с хостом остаётся непроверенным.
