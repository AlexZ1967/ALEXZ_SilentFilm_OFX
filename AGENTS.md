# Инструкции ALEXZ SilentFilm OFX

- Общение, документация и обычные комментарии — по-русски. Идентификаторы, API и описания функций в docstring/Doxygen — по-английски.
- Рабочий проект: `/home/alex/Projects/ALEXZ_SilentFilm_OFX`. Не изменять существующий `ComfyUI_ALEXZ_SilentFilm`, ComfyUI, Resolve или установленные SDK.
- В новом диалоге сначала читать `docs/SESSION_HANDOFF.md`; полный план и референсы открывать по текущему этапу, не перечитывать весь исходный Python-проект без необходимости. После завершённого этапа обновлять handoff подтверждёнными результатами и следующим шагом.
- Карта Python-референса и решений прежнего проекта: `docs/REFERENCE_MAP.md`. Его правила Python/Conda/Make не переносятся в нативный C++/OpenFX-проект.
- Папки workspace с суффиксом `REFERENCE` — только справка. VS Code read-only защищает редактор, но не заменяет этот запрет для инструментов агента.
- Базовая платформа первого этапа — Linux x86_64 и установленный Resolve Studio 20.2. Windows/macOS — следующие целевые платформы; не заявлять поддержку до проверки.
- Основная локальная справка: `/opt/resolve/Developer/OpenFX`. SDK только читать; заголовки подключать через настройку CMake, не копировать автоматически.
- Вычислительное ядро отделять от OpenFX и API ОС. Не добавлять зависимости от Python, PyTorch или ComfyUI в процесс Resolve.
- Проверки, сборки, тесты и запуск Resolve выполняет пользователь. Не запускать их самостоятельно без прямой просьбы. Давать точные команды и не приписывать непроверенным изменениям PASS.
- Для сборки и проверок использовать системные CMake, CTest и компилятор C++17 (GCC/Clang). Conda environment не требуется; команды передавать без `conda run`.
- Не устанавливать плагин в системные каталоги и не перезапускать Resolve без прямой просьбы.
- Render должен допускать произвольный порядок кадров и несколько экземпляров. Host images освобождать в пределах action, не сохранять их указатели между вызовами.
- Параметры и plugin ID прототипа не выдавать за финальный публичный контракт SilentFilm.
